Fibonacci Series in C

📌 Project Description

This project is a simple C program to print the Fibonacci series up to a given number of terms.

The Fibonacci series is a sequence in which each number is the sum of the two preceding numbers. The series starts with 0 and 1.

💻 Example

Input:

Enter the number of terms: 7

Output:

Fibonacci Series: 0 1 1 2 3 5 8

⚙️ Algorithm

1. Start the program.
2. Read the number of terms from the user.
3. Initialize the first two numbers as "0" and "1".
4. Print the first two numbers as required.
5. Calculate the next number by adding the previous two numbers.
6. Repeat until the required number of terms is printed.
7. Stop the program.

🛠️ Technologies Used

- Programming Language: C
- Compiler: GCC
- Platform: Any system that supports C programming

▶️ How to Run the Program

1. Save the source code as "fibonacci.c".

2. Open a terminal in the folder containing the file.

3. Compile the program:
   
   gcc fibonacci.c -o fibonacci

4. Run the program:
   
   Windows:
   
   fibonacci.exe
   
   Linux/macOS:
   
   ./fibonacci
